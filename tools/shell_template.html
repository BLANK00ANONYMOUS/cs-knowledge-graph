How this app works

Your knowledge graph is a map of concepts linked by prerequisites. You never read the books cover to cover — the tutor teaches short lessons and checks facts against them. One loop, repeated:

1 · 📘 Learna bite-size lesson on a concept that's ready (its prerequisites are done)
2 · 🎓 Quizsets your real mastery 0–5; 3+ unlocks what comes next
3 · 🛠 Applya challenge or project milestone that uses it
4 · 🔁 Reviewshort mixed quizzes when it's due, so it sticks
🏠 Today
Start here every day: one button runs today's session. New? Follow the “Start here” checklist.
🧠 Graph & Tutor
Find or ➕ add any topic (the graph grows as you go), see its learning path, then Learn or Quiz in the tutor panel.
🛠 Build
Your GitHub projects, open-source issues to work on, and project ideas that practise concepts.
🏁 Challenges
Codeforces-style problems for real development work, judged with hidden tests and rated.
💼 Jobs
Roles you're aiming for, the skills they need, how ready you are — missing skills become graph concepts.

Work you start in one section keeps running when you switch to another — a spinner on the tab shows it's busy, a green dot means it finished.
